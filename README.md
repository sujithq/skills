# skills
Collection of skills

## Available skills

- `pdf-to-markdown`: Convert PDF and Office files to Markdown with `markitdown`.
- `commit-message-writer`: Generate conventional commit messages from code change summaries.

## Install

Install all skills from this repo:

```powershell
npx skills add sujithq/skills
```

Install one skill:

```powershell
npx skills add sujithq/skills/pdf-to-markdown
npx skills add sujithq/skills/commit-message-writer
```

Skills are also installable via the [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces):

```
/plugin marketplace add sujithq/skills
/plugin install sujithq-skills@sujithq-skills
```
